# ani-id-cli Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a POSIX shell CLI that searches, streams, and downloads anime from otakudesu.blog.

**Architecture:** One executable script. Pure parsing functions take HTML on stdin and print tab-separated records; network, menu, player, and history functions wrap them. Tests source the script with `ANI_ID_CLI_LIB=1` and feed fixtures.

**Tech Stack:** POSIX `sh`, `curl`, `sed`, `grep`, `awk`, `fzf`, `mpv`/`vlc`, `yt-dlp`.

**Spec:** `docs/superpowers/specs/2026-11-22-ani-id-cli-design.md`

## Global Constraints

- POSIX `sh`; no bash-only syntax.
- Base URL only from `ANI_ID_BASE`, default `https://otakudesu.blog`.
- Stream requests send `Referer: {base}/`.
- Parsers must not touch the network; tests use `tests/fixtures`.
- No output on success except the requested records.

## Review Focus

- HTML entities in titles (`&#039;`, `&amp;`) must be decoded for display.
- Episode numbers such as `8.5` and `1000` must sort numerically.
- Episode page may have several iframes/ads; only `div.player-embed` counts.
- Mirror AJAX may omit a quality; fall back to best with a warning.
- Download filenames must strip `/` and other unsafe characters.
